## Reporting a Vulnerability

Please report security issues and vulnerabilities privately through GitHub Security Advisories:
https://github.com/vishal-muralidharan/razorpay-buildathon/security/advisories/new

When submitting a report, please include:
- A description of the vulnerability and its potential impact
- Step-by-step instructions or a minimal proof of concept to reproduce the issue
- Affected endpoints, parameters, or components

We review and address reports on a best effort basis. We ask that you do not disclose security vulnerabilities publicly until they have been investigated and addressed.
